# Dhandho Weekly — Public Data Feed

This repo hosts only the **published weekly results** (`latest.json`, `vol{N}.json`)
that the landing page reads. The engine (universe, fetch, filter, scoring logic)
is kept private.

- `latest.json` — most recent issue's screened picks
- `vol{N}.json` — archived snapshot per volume

Served via GitHub Pages at:
`https://sosmos3218-bot.github.io/dhandho-data/latest.json`
